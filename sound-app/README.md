# 愛美のサウンドケア

サーバー不要の、ファイルを置くだけで動くスマホ向けアプリ（PWA）。

## できること
- **セルフチェック**：5つの質問 → いまに合う音を3つ提案（愛美のひとこと付き）
- **サウンド**：周波数（174〜963Hz）、バイノーラルビート（2/6/10/15Hz）、ノイズ（雨音・波の音）。タイマー・音量・うしろに流す音・お気に入り
- **1/fゆらぎ**：なし／ひかえめ／ふつう／しっかり。周波数の音は音量と左右の位置、バイノーラルは音量だけ、ノイズは音量とこもり具合をゆらす（Hz自体は変えない）。画面のオーブも同じゆらぎで動く
- **きろく**：聴く前／後の気分、メモ、気分の変化グラフ、連続日数、相性のよい音、ゆらぎあり／なしの比較
- **せってい**：よび名、いつもの時間、いつもの1/fゆらぎ、バックアップ保存／復元、全データ削除

データは使う人のスマホのブラウザ内にだけ保存される（どこにも送信しない）。

## ネットに公開する方法（どれか1つ）

### いちばん簡単：Netlify Drop
1. https://app.netlify.com/drop を開く（無料アカウント作成が必要）
2. この `sound-app` フォルダをまるごとドラッグ＆ドロップ
3. 出てきたURLをスマホで開く → 「ホーム画面に追加」

### GitHub Pages
1. このフォルダの中身をGitHubのリポジトリに入れる
2. Settings → Pages → ブランチを選んで保存
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で開ける

※ どちらも https になるので、ホーム画面追加・オフライン利用もそのまま使える。

## カスタマイズ
`index.html` の上のほうにある `APP` を書き換える。
- `name`：アプリ名
- `contactUrl`：LINE公式アカウントなどのURLを入れると、ホームに「相談する」ボタンが出る

中身を更新したら、`sw.js` の `CACHE_NAME`（例：`soundcare-v1` → `soundcare-v2`）も変えておくと、使っている人のスマホに確実に反映される。

## 注意
- リラックス・気分転換用のアプリで、医療機器ではない。宣伝で「治る」「改善する」などの効果は言わないこと
- スマホをロックすると音が止まることがある（ブラウザの仕様）
